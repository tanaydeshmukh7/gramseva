# Gramसेवा — Gram Panchayat Gohgaon Management Software
> **ग्रामपंचायत गोहगाव संगणकीकृत नोंदवही, कर आकारणी व वसुली व्यवस्थापन प्रणाली**  
> *तालुका: रिसोड, जिल्हा: वाशिम (महाराष्ट्र शासन)*

---

## 📌 प्रकल्प परिचय (Project Overview)

**Gramसेवा** हे ग्रामपंचायत गोहगावच्या दैनंदिन कामकाजासाठी तयार करण्यात आलेले संपूर्ण वेब अ‍ॅप्लिकेशन आहे. हे सॉफ्टवेअर मूळ **Google Spreadsheet** (`ग्रामपंचायत गोहगाव .xlsx`) मधील सर्व **२६ च्या २६ वर्कशीट्स**, सूत्रे (formulas), कर आकारणी नियम आणि शासकीय कागदपत्रांचे फॉरमॅट अचूकपणे जतन करते.

**This is not an over-complicated ERP. It is the real Gram Panchayat spreadsheet converted into administrative software.**

## 🎨 डिझाईन वैशिष्ट्ये (Design & UI/UX)

- **Strict Light Mode Only:** प्रशासकीय कामासाठी पांढरी आणि सौम्य राखाडी पार्श्वभूमी.
- **कलर पॅलेट:** प्राथमिक हिरवा (`#245C45`), सौम्य हिरवा (`#EAF1EC`), पांढरा (`#FFFFFF`), मजकूर (`#252A27`), बॉर्डर्स (`#E1E5E1`).
- **टायपोग्राफी:** इंग्रजीसाठी `Inter` आणि मराठीसाठी `Noto Sans Devanagari`.
- **प्रिंट सुसंगतता:** सर्व कायदेशीर कागदपत्रे A4 साईजमध्ये थेट प्रिंट व PDF डाऊनलोड करण्यासाठी अनुकूल.

## 🚀 सुरू करण्यासाठी (Getting Started)

### १. आवश्यकता (Prerequisites)
- Node.js (v18 किंवा नवीन)
- npm

### २. इन्स्टॉलेशन (Installation)
```bash
git clone https://github.com/tanaydeshmukh7/gramseva.git
cd gramseva
npm install
```

### ३. डेव्हलपमेंट सर्व्हर (Run Locally)
```bash
npm run dev
# किंवा प्रोडक्शन बिल्डसाठी:
npm run build
npm run start
```
स्थानिक सर्व्हर: [http://localhost:3000](http://localhost:3000)
